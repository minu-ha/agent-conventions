# 규칙의 한국어와 읽기 흐름 개선

## 범위와 기준

현재 `main`의 미커밋 품질 개선을 보존하고 CSS 34개, React 52개, TypeScript 42개 규칙을 다듬는다.
`korean-language`라는 단일 스킬은 로컬에서 찾지 못했으므로 저장소에 설치된
`grammar-checker`, `humanizer`, `style-guide`를 적용한다.

- 결론과 이유를 첫 한두 문장에 쓰고, 조건별 선택은 표로 비교한다.
- 같은 내용을 표와 문단에서 반복하지 않는다. 기술 용어와 예외는 보존한다.
- 설명이 길면 중복을 먼저 압축한다. 적용 조건이 다른 독립된 판단은 분리 여부를 검토한다.
- 텍스트 구조도는 `Correct` 예제에 두고, 규범은 본문에도 남긴다.
- Mermaid는 현재 뷰어가 지원하지 않으므로 표와 텍스트 코드 블록을 사용한다.
- 영어 제목, 규칙 ID, 적용 조건과 관계, 실행 예제의 동작은 유지한다.

## 측정 방법

수정 전후 비교 기준은 이전 턴의 개선이 반영된 작업 트리다. `HEAD`와의 누적 변경량과 구분한다.
본문은 frontmatter, 영어 제목, Impact, 코드 예제를 제외하고 첫 `Incorrect` 앞의 설명으로 집계한다.
줄 수는 공백 줄을 제외하며 표의 각 행도 한 줄로 센다.
설명 길이 감소와 표 사용량을 함께 기록해 단순 줄 합치기를 개선으로 계산하지 않는다.
줄 수가 줄어도 화면 높이는 표의 줄바꿈과 여백에 따라 달라질 수 있으므로 실제 HTML도 확인한다.
