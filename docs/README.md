# 팀 컨벤션

React, CSS, TypeScript, Figma 코딩 규칙을 사람이 읽는 사이트입니다.
정본은 저장소의 `skill/<skill>/rules/*.md`이고, 규칙 페이지는 `npm run build`가 `docs/convention/`에 생성합니다.

| 스킬 | 함께 적용 |
| --- | --- |
| [React](convention/react.md) | [TypeScript](convention/typescript.md) 항상, [CSS](convention/css.md) 조건부 |
| [CSS](convention/css.md) | [TypeScript](convention/typescript.md) 조건부 |
| [TypeScript](convention/typescript.md) | 없음 |
| [Figma](convention/figma.md) | [React](convention/react.md) 조건부, [CSS](convention/css.md) 조건부 |

왼쪽 목록에서 스킬을 고르면 개요와 전체 규칙 표가 나오고, 그 아래 섹션이 한 장씩 있습니다.
설계 배경과 측정 기록은 Research, 저장소 도구는 Development에 있습니다.
