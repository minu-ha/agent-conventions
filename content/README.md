# agent conventions

React, CSS, TypeScript, Figma 코딩 규칙을 사람이 읽는 사이트입니다.

| 규칙 | 함께 보는 규칙 |
| --- | --- |
| [React](public/convention/react.md) | [TypeScript](public/convention/typescript.md) 항상, 스타일을 바꿀 때 [CSS](public/convention/css.md) |
| [CSS](public/convention/css.md) | TSX 클래스 계약을 함께 바꿀 때 [TypeScript](public/convention/typescript.md) |
| [TypeScript](public/convention/typescript.md) | 없음 |
| [Figma](public/convention/figma.md) | 바뀌는 쪽의 [React](public/convention/react.md), [CSS](public/convention/css.md) |

왼쪽에서 규칙 묶음을 고르면 개요와 전체 규칙 표가 나오고, 그 아래 섹션이 한 장씩 있습니다.
규칙마다 한 줄 요지, 판정 기준, 잘못된 예와 올바른 예, 함께 볼 규칙이 있습니다.
설계 배경과 측정 기록은 Research, 저장소 도구는 Development에 있습니다.
